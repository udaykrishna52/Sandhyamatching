# Sandhya Matching Collections

A premium luxury React boutique website for **Sandhya Matching Collections** — women's fashion specializing in matching blouse materials, designer blouses, sarees, fancy laces, borders, fabrics, bridal collections, and fashion accessories.

## Tech Stack

- **React 19** + **Vite 6**
- **Framer Motion** — scroll animations, parallax, transitions
- **React Icons** — elegant iconography
- Google Fonts: Playfair Display + Poppins

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build for Production

```bash
npm run build
npm run preview
```

## Before Going Live

1. **WhatsApp number** — update `WHATSAPP_NUMBER` in `src/data/content.js` (currently `919999999999`)
2. **Contact details** — update address, phone, email in `src/components/Contact.jsx`
3. **Google Maps** — replace the iframe embed URL in Contact with your exact location
4. **Products & gallery** — edit arrays in `src/data/content.js`
5. **Social links** — update Instagram/Facebook URLs throughout
